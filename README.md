# NodeseekLite

位置：NodeSeek 论坛。  
动作：提供轻量油猴插件。  
结果：增强黑名单、好友、关键词过滤、快捷回复、图床和数据同步。

## 安装

位置：油猴插件。  
动作：打开脚本安装地址。  
结果：安装 `Ns.user.js`。

```text
https://raw.githubusercontent.com/xixu520/nodeseek/main/Ns.user.js
```

位置：脚本设置。  
动作：点击检查更新。  
结果：读取 GitHub 最新版本。

## 功能

位置：主面板。  
动作：显示常用功能入口。  
结果：支持折叠、移动端显示和主题切换。

位置：关键词过滤。  
动作：按回车添加关键词。  
结果：关键词以色块显示，右上角可以删除。

位置：高亮关键词。  
动作：匹配帖子标题。  
结果：只高亮标题，不高亮回复内容。

位置：黑名单和好友。  
动作：管理用户名单。  
结果：保留本地存储数据格式。

位置：快捷回复。  
动作：管理常用回复。  
结果：可快速填入 NodeSeek 回复框。

位置：图床。  
动作：打开 NodeImage 面板。  
结果：支持上传和插入论坛编辑器。

位置：数据管理。  
动作：导入、导出和 WebDAV 同步。  
结果：备份插件数据。

## 本地开发

位置：项目根目录。  
动作：安装 Node.js 后运行检查。  
结果：合并模块并生成脚本。

```bash
npm run check
```

位置：`src/module-order.json`。  
动作：控制模块合并顺序。  
结果：生成根目录 `Ns.js` 和 `Ns.user.js`。

位置：`src/meta.js`。  
动作：维护油猴脚本头。  
结果：控制版本号、更新地址和授权。

## 发布

位置：GitHub。  
动作：提交 `Ns.user.js`。  
结果：油猴可从 Raw 地址检查更新。

位置：本地数据文件。  
动作：不提交 `NS综合插件.storage.json`。  
结果：避免上传个人数据和密码。
