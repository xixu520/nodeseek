# NodeseekLite

位置：NodeSeek 论坛。
动作：提供单文件油猴脚本。
结果：增强名单、过滤、快捷回复、图床、阅读记录、自动签到和数据备份。

## 安装

位置：油猴。
动作：打开安装地址。
结果：安装 `Ns.user.js`。

```text
https://raw.githubusercontent.com/xixu520/nodeseek/main/Ns.user.js
```

位置：脚本设置。
动作：点击“检查更新”。
结果：读取 GitHub 上的最新版本，并打开油猴更新页。

## 当前特性

位置：主面板。
动作：显示常用入口。
结果：包含设置、同步、日志、查看黑名单、查看好友、关键词过滤、快捷回复和 NS 图床。

位置：主面板。
动作：折叠为侧边按钮。
结果：保留“刷”按钮；在帖子页额外显示“首”和已选择的快捷回复按钮。

位置：首页折叠按钮。
动作：点击“高亮数目”。
结果：只显示高亮帖子；再次点击恢复全部帖子，并用颜色区分当前状态。

位置：界面。
动作：适配浅色、深色和移动端。
结果：按钮大小统一，弹窗宽度和高度会随屏幕调整。

位置：用户名旁。
动作：添加“拉黑”和“添加好友”按钮。
结果：可直接写备注，并在页面中标记黑名单和好友。

位置：用户名旁。
动作：读取用户资料。
结果：显示加入天数和等级；加入时间小于 30 天、等级小于等于 1 级时使用提醒色。

位置：用户资料请求。
动作：排队读取。
结果：最多同时请求 2 个用户，每次请求间隔至少 500ms；失败和限流会短暂停止重复请求。

位置：黑名单。
动作：记录用户名、备注、拉黑时间、来源页面和楼层。
结果：列表页和私信页会显示对应标记，支持查看和移除。
结果：新增本地黑名单时，会同步调用 NodeSeek 官方屏蔽用户接口。

位置：好友。
动作：记录用户名、备注、添加时间和私信地址。
结果：支持查看、修改备注和移除。

位置：关键词过滤。
动作：输入后按回车。
结果：关键词以色块显示，右上角可删除。

位置：关键词过滤。
动作：隐藏或高亮内容。
结果：屏蔽关键词会隐藏内容；高亮关键词只作用于标题，不作用于回复内容。

位置：关键词过滤。
动作：设置屏蔽等级和加入天数。
结果：默认屏蔽等级 0、1，并屏蔽加入天数小于等于 30 天的帖子列表项。

位置：关键词过滤。
动作：设置白名单用户名。
结果：命中白名单的用户不参与隐藏和高亮处理。

位置：快捷回复。
动作：保存常用回复。
结果：可搜索、编辑、删除、插入到 NodeSeek 富文本回复框。

位置：快捷回复。
动作：勾选回复作为最小化按钮。
结果：帖子页折叠后显示“回1”“回2”等按钮。

位置：快捷回复。
动作：开启插入后自动提交。
结果：插入回复后自动点击页面发送按钮。

位置：NS 图床。
动作：打开 NodeImage 面板。
结果：支持获取和保存 API Key、上传图片、生成 Markdown，并插入论坛编辑器。

位置：NodeImage 图片。
动作：访问论坛时优化 `cdn.nodeimage.com` 图片。
结果：提前建立连接，并按视口位置设置图片加载优先级。

位置：阅读记忆。
动作：记录已打开的帖子。
结果：帖子标题会按设置颜色显示为已读，可清除记录。

位置：浏览历史。
动作：记录访问过的帖子、主题和文章。
结果：保存标题、链接、时间和访问次数。

位置：设置。
动作：开启“新标签页打开帖子”。
结果：帖子链接会在新标签页打开。

位置：设置。
动作：开启“屏蔽 URL 跳转提醒”。
结果：可选择全放行或白名单模式，直接跳过 NodeSeek 外链跳转页。

位置：自动签到。
动作：每天首次打开脚本后执行。
结果：在后台请求 NodeSeek 签到接口，支持固定和随机模式。

位置：日志。
动作：记录插件操作。
结果：支持按关键词搜索和按类型筛选，最多保存 100 条。

位置：数据管理。
动作：导入和导出。
结果：覆盖黑名单、好友、日志、浏览历史、快捷回复、签到设置、关键词过滤、笔记、阅读记忆和其他设置。

位置：WebDAV 同步。
动作：配置地址、账号、密码、间隔和字段。
结果：数据保存到 WebDAV 地址内的 `nodeseek_data.json`；密码优先保存到油猴脚本存储。
结果：仓库不内置个人 WebDAV 地址，用户在设置中填写自己的 WebDAV 地址即可。

位置：WebDAV 同步。
动作：检测本地和远端修改时间。
结果：手动同步遇到冲突时可选择使用本地或远端。

位置：笔记。
动作：保存标题和内容。
结果：支持导入、导出和简单管理。

位置：统计工具。
动作：保留鸡腿统计、热点统计和 VPS 计算器基础弹窗。
结果：可被脚本内部或控制台调用。

## 已移除内容

位置：旧功能。
动作：移除旧版收藏模块、旧版查看模块和表情模块。
结果：当前版本不再维护这些入口。

位置：快捷编辑。
动作：移除独立快捷编辑模块。
结果：回复相关能力统一由快捷回复处理。

## 数据与隐私

位置：本地数据。
动作：使用浏览器本地存储和油猴存储。
结果：黑名单、好友、过滤规则、快捷回复、阅读记录和同步配置保存在本机。

位置：敏感数据。
动作：WebDAV 密码和 NodeImage API Key 优先保存到油猴存储。
结果：不应提交个人存储文件。

位置：仓库。
动作：不提交 `NS综合插件.storage.json` 和 `NS综合插件.options.json`。
结果：避免上传个人数据。

## 本地开发

位置：源码目录。
动作：按模块维护。
结果：`src/module-order.json` 控制合并顺序。

```text
src/core/       入口、样式、面板、设置、同步、启动逻辑
src/modules/    黑名单、好友、历史、过滤、快捷回复、图床、签到、统计、笔记
src/meta.js     油猴脚本头
scripts/build.js 合并脚本
```

位置：项目根目录。
动作：运行检查。
结果：生成根目录 `Ns.js` 和 `Ns.user.js`。

```bash
npm run check
```

位置：发布文件。
动作：提交 `Ns.user.js`。
结果：油猴可通过 GitHub Raw 地址检查更新。
